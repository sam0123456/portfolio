## 🚀 Overview

- **Design Philosophy**: Minimalist, human-crafted developer portfolio inspired by Linear and Vercel. Zero artificial buzzwords or bloated dependencies.
- **Performance**: 100% Vanilla HTML5, CSS3, and JavaScript with instant load times and responsive cross-device layout.
- **Key Features**:
  - Direct WhatsApp & Email messaging integration.
  - Official downloadable Resume PDF (`assets/resume.pdf`).
  - Flagship MERN project case studies: **ShiftPe** and **Hostel/PG Complaint System**.
  - Verified credentials from RGPV Bhopal (MCA) & AKU Patna (BCA).
  - Dark / Light mode toggle with local storage persistence.

## 💻 Local Development

Run locally using Python's built-in HTTP server or any static file server:

```bash
# Using Python
python3 -m http.server 8080

# Or using Node / npx
npx serve .
```

Then visit `http://localhost:8080` in your web browser.
